# Akshaya Mahesh Kumar · Portfolio

A single-page static site: `index.html` only. No build step and no dependencies. Fonts load from Google Fonts.

## Deploy with Claude Code

Open this folder in Claude Code and paste:

> This folder is my static portfolio site (just index.html). Initialize a git repo, create a new public GitHub repo called `portfolio` under my account, push it, then deploy it on Vercel as a static site with no build step and no framework preset. Give me the live URL when it's done.

The design is maintained on the Claude Design canvas. When the content changes there, re-export `index.html` into this folder and push again. Vercel redeploys automatically on push.
